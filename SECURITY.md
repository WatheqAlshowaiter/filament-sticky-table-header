# Security Policy

## Supported Versions

Only the latest released version of this package is actively supported with security fixes.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not** open a public GitHub issue.

Instead, report it privately using [GitHub's private vulnerability reporting](https://github.com/WatheqAlshowaiter/filament-sticky-table-header/security/advisories/new), or email the maintainer directly.

Please include as much detail as possible:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Any relevant code, configuration, or environment details

You should expect an initial response within a few days. Once a fix is available, a new release will be published and the reporter will be credited unless anonymity is requested.
